## One reusable agent, one focused thread

Sidekick stores reusable agents with instructions, selected skills, and
optional execution defaults. BB's native live picker supplies provider, model,
reasoning, service tier, and permission choices. A shared instruction block in
Sidekick's settings applies before each agent's own instructions.

Each start creates exactly one visible BB thread in a project selected
explicitly.

## Empty by default

Sidekick does not seed examples. Create the first agent from **Agents** in the
sidebar or with `bb sidekick create`.

## Deliberately small

No teams, DAGs, task presets, workflow canvas, orchestrator conversation,
handoffs, live-agent objects, or automations are included.
