## One reusable profile, one focused thread

Sidekick stores reusable profiles with hidden instructions and optional
provider, model, reasoning, permission, preferred-skill, and behavior defaults.
A shared instruction block in Sidekick's plugin settings applies to every
profile before its profile-specific instructions. Each start creates exactly
one visible BB thread in a project you select explicitly.

## Empty by default

Sidekick does not seed example profiles. Create the first profile in the
Sidekick sidebar page or with `bb sidekick create`.

## Deliberately small v1

No teams, DAGs, task presets, workflow canvas, orchestrator conversation,
handoffs, live-agent objects, or automations are included.
